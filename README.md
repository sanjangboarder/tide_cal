# 2027년 구글 캘린더 서해 물때표 (7물때식)

2027년 서해안 7물때(1~13물, 조금, 무시)를 구글 캘린더/애플 캘린더에서 구독 및 확인할 수 있는 프로젝트입니다.

---

## 📁 주요 파일 구성
- [`generate_tides_2027.py`](file:///home/ubuntu/ical/generate_tides_2027.py): 2027년 1년치 물때 일정을 계산하여 `.ics` 표준 파일로 생성하는 스크립트
- [`tides_west_2027.ics`](file:///home/ubuntu/ical/tides_west_2027.ics): 생성 완료된 2027년 365일 서해 7물때 캘린더 파일 (구글 캘린더 호환)
- [`server.py`](file:///home/ubuntu/ical/server.py): 로컬 테스트 및 ICS URL 제공용 간이 HTTP 서버

## 📅 구글 캘린더에 추가하는 방법

### 방법 1: URL로 구독하기 (추천 - 자동 갱신 및 토글 관리)
1. GitHub Pages, GitHub Gist, 또는 개인 서버에 `tides_west_2027.ics` 파일을 업로드하여 공개 URL을 확보합니다.
   - 예: `https://raw.githubusercontent.com/.../tides_west_2027.ics`
2. [Google Calendar](https://calendar.google.com) 접속
3. 좌측 메뉴 **다른 캘린더** 옆의 **`+` 버튼** 클릭 → **`URL로 추가`** 선택
4. 확보한 `.ics` 파일의 URL을 붙여넣고 **`캘린더 추가`** 클릭
5. 언제든 좌측 체크박스를 통해 물때 일정을 켜고 끌 수 있습니다.

### 방법 2: ICS 파일 직접 가져오기 (오프라인 사용 시)
1. 구글 캘린더 좌측 **다른 캘린더** `+` → **새 캘린더 만들기** (이름: "서해 물때표")
2. 구글 캘린더 우측 상단 ⚙️(설정) → **가져오기 및 내보내기**
3. `tides_west_2027.ics` 파일을 선택하고, 추가할 캘린더로 방금 만든 "서해 물때표"를 지정한 뒤 **가져오기** 클릭

## 💡 지역별 세분화(만조/간조, 고저차) 확장 아이디어

향후 인천, 태안, 안흥, 군산, 보령 등 특정 항구별 조석 정보(간조/만조 시각, 조위)를 추가할 때 적용할 수 있는 설계 모델입니다:

### 1. 데이터 수집 방안
- **국립해양조사원(KHOA) 바다누리 OpenAPI**:
  - 주요 조석관측소(130여 개)의 연간 조석예보 데이터(고조/저조 시각, 예측 조위 cm) 제공
- **바다타임 웹 조석표 연동**:
  - 주요 포인트별 조석 시간 데이터 수집

### 2. 캘린더 UI 표현 방식 (2가지 옵션)
- **옵션 A: 종일 일정 요약형 (시인성 최상 - 추천)**
  - 제목: `[인천 7물(사리)] 만 05:20(850) 간 11:42(120)`
  - 상세 내용:
    - 🌊 오전 만조: 05:20 (850cm)
    - 🔻 오전 간조: 11:42 (120cm, 조차 730cm)
    - 🌊 오후 만조: 17:50 (860cm)
    - 🔻 오후 간조: 23:55 (110cm)
    - 🤿 해루질 최적 시간대(간조 2시간 전후) 가이드
- **옵션 B: 시간대별 이벤트형 (타임라인 알림형)**
  - 만조와 간조 시각에 각각 30분~1시간짜리 일정을 개별 생성하여 구글 캘린더 타임라인에 직접 표시
  - 알림 설정(간조 1시간 전 푸시 알림) 가능

### 3. 동적 URL 구독 아키텍처 (Serverless / API)
- Cloudflare Workers 또는 AWS Lambda를 활용한 On-demand ICS 생성:
  - `https://tides.example.com/api/calendar?port=incheon&year=2027`
  - URL 파라미터만 변경하면 전국 어느 항구의 캘린더든 즉시 구독 가능하도록 구성
